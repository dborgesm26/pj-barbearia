# PJ Barbearia

Landing page em React + Vite + Tailwind CSS + Framer Motion.

Comandos (no computador ou no Claude Code):

    npm install
    npm run dev      # desenvolvimento
    npm run build    # gera a pasta dist

Publicação (Vercel ou Netlify): importe o repositório do GitHub.
Build command: `npm run build` | Output directory: `dist`

Para editar: preços, Instagram e links ficam no topo de `src/App.jsx`.
